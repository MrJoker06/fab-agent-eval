# 本轮验证记录

验证日期：2026-10-09。Windows / Python 3.12；使用已有 EvalScope 1.12.0、bfcl-eval 2025.10.27.1 环境进行只读依赖验证，没有安装、升级或改写必要测试环境。

| 验证项 | 结果 |
| --- | --- |
| 预算与范围选择 | 三模型独立补充预算；默认 26 个 RULER 子任务及 21 个 BFCL 子任务；部分补跑保持预算基线 |
| StratifiedSampler | 固定 seed 结果可复现，不放回，保留原始顺序 |
| RULER 官方指标 | 13 个任务的正确、错误、部分匹配及清洗规则通过 |
| 真实 BFCL 数据 | 20 个离线类别及格式敏感性均加载成功，参考答案 ID 对应 |
| Memory 依赖 | 选择完整场景，前置依赖闭包保留；三后端材料均可加载 |
| MiniLM | 显式本地完整目录，CPU 加载，384 维输出，不依赖新 Hub 缓存 |
| 模拟单轮推理 | 实际 SDK 参数与预算转发正确，已知工具调用通过官方评分并生成 HTML |
| 模拟 RULER 推理 | 合成输入接入原生 EvalScope，官方批量分数及 HTML 正确 |
| 模拟格式与记忆 | 26 个配对变体产生报告；完整 memory_kv 场景执行前置推理并生成快照 |
| 失败无重试 | HTTP 500 时 BFCL、RULER 均只请求一次，异常记录保留，任务返回失败 |
| BFCL 成绩范围 | 报告不添加官方 OVERALL；类别单独报告 |
| 生命周期 | 临时服务按上下文重启，失败后继续记录并清理，端口最终释放 |
| 组合入口 | 必要/补充顺序执行，数组参数传递正确，补充失败不改变必要完成状态 |
| 组合 DryRun | 必要预算仍 24h；原 MATH-500 25 题、CMMLU 102 题保持；补充独立 6h，合计规划 30h |
| 冻结范围 | 本轮开始前记录的 10 个原有文件逐文件内容指纹保持一致 |

tests/test_offline.py 包含数据、官方指标和模拟 API 检查；tests/test_lifecycle.py 包含汇总覆盖、服务清理及两层独立状态检查。最后的原生单轮/RULER/失败回归、格式与记忆回归、三项生命周期回归均通过。故意返回错误的测试用于确认失败识别，不代表模型答错或实际服务故障。

**验证边界：** RULER 使用合成短输入与冻结官方评分代码；测试 tokenizer 为本机已有 Qwen3.5-0.8B tokenizer，模拟 API 不包含真实候选模型。没有运行三个 GGUF，没有进行正式 16K/32K 长输入推理，也没有测量 A10 的显存和耗时。目标机器仍须准备正式材料、配置对应 tokenizer / GGUF / runtime 并校准预算。默认上下文与秒/单位是规划假设。
